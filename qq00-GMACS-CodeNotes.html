GMACS code notes

Model time frame-related variables

  • “terminal year”: final complete model year (the OFL would be determined for terminal year + 1)

  • syr: model start year [data file]

  • nyr: nominal model end year/terminal year (but not necessarily - depends on nyrRetro and nproj) [data file]

  • nyrRetro1: integer set by commandline “-retro x” (-1 if not set) [commandline]

  • nyrRetro: integer set in gmacs.dat file to specify number of peels to drop [dat, not data, file]

    • overridden by nyrRetro1, if it is set
    • after being read from gmacs.dat (and possibly set to the value of nyrRetro1), it is saved as nyrRetroNo, then converted to \(nyrRetro = nyr-nyrRetro\), the terminal year of the retrospective peel

  • nyrRetroNo: original value (after nyrRetro1check ) of nyrRetro

  • pyr: terminal year for projections [prj file]

  • nproj: \(nproj = pyr - nyr\)

  • Nyears: \(Nyears =(nyrRetro-syr+1)\)

  • Nyears2: \(Nyears2 =(nyrRetro+1-syr+1)\)

  • Nyears3: \(Nyears3 = 2*nfleet*nsex*(nyr+1-syr+1)\)

  • Nyears4: \(Nyears4 =(nyrRetro+nproj+1-syr+1)\)

  • nprojVec: \(nprojVec = max(2,nproj+1)\)

  • Env_vars_used(syr,nyr+nproj,1,Num_env_vars+1)

  • Rec_bias(syr,nyr)

  • model_controls(1): first year of rec dev estimates

  • rdv_syr: \(rdv_syr = int(model_controls(1))\)

  • model_controls(2): last year of rec dev estimates

  • rdv_syr: rdv_eyr = int(model_controls(2) -= (nyr-nyrRetro))$ **why subtracting here: clearer to subtract nyrRetroNo*

  • CustomSelex(1,Nyears3,1,nclass)

  • setting CustomSelex:

    • loop over it=1:2; h=1:nsex; k=1:nfleet;
    • offset \(= (it-1)*nfleet*nsex*(nyr+1-syr+1)+nfleet*(nyr+1-syr+1)*(h-1)+(nyr+1-syr+1)*(k-1)\)
    • loop over iyr=syr:nyr+1; ii=1:nclass
      • *(ad_comm::global_datafile) >> CustomSelex(offset+iyr-syr+1,ii);
