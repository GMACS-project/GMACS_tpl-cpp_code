Objective Function

This section documents the objective function defined in the gmacsbase.TPL file that is minimized to find the “best” set of parameter values for a GMACS assessment model.

Objective function

The objective function is referred to as nloglike in the gmacsbase.TPL file. It’s value is the result of summing negative log-likelihood components expressing the (mis)fits to the input data, priors on parameters, and penalties.

      objfun =  w_nloglike + 
                sum(elem_prod(nlogPenalty,Penalty_emphasis)) + 
                sum(priorDensity) + 
                TempSS + 
                grwthPosFun;

      w_nloglike = sum(elem_prod(nloglike(1),catch_emphasis)) + sum(elem_prod(nloglike(2),cpue_emphasis)) + sum(elem_prod(nloglike(3),lf_emphasis));
      w_nloglike += sum(nloglike(4));
      w_nloglike += sum(nloglike(5))*tag_emphasis;
      w_nloglike += sum(nloglike(6));
      w_nloglike += sum(nloglike(7))*mmodLkWgt;

Data components

    1. fishery catch : sum(nloglike(1))
    1. index catch : sum(nloglike(2))
    1. size comps : sum(nloglike(3))
    1. recruitment : sum(nloglike(4))
    1. tagging growth : sum(nloglike(5))
    1. growth data : sum(nloglike(6))
    1. male mat. og.s : sum(nloglike(7))
    1. effort expansion: sum(nloglike(8))

Penalties

Most penalties are assigned in the nlogPenalty vector, which has 13 components:

  • 1: A penalty on log_fdev (male+combined; female) to ensure the fishing mortality devs sum to zero

       dvariable s     = mean(log_fdev(k));
   nlogPenalty(1) += Penalty_fdevs(k,1)*s*s;
   if (nsex > 1){
     dvariable r     = mean(log_fdov(k));
     nlogPenalty(1) += Penalty_fdevs(k,2)*r*r;
   }

  • 2: A penalty on mean F’s to regularize the solution

Another penalty, grwthPosFun, is intended to keep mean growth estimates positive.
